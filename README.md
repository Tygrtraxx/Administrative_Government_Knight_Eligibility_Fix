# Administrative Government - Knight Eligibility Fix
**Administrative Government - Knight Eligibility Fix** is a mod for [Crusader Kings III](https://store.steampowered.com/app/1158310/Crusader_Kings_III/) that fixes an issue with the Administative Government and the Invite Champions decision.
It does this by fixing Paradox's mistake of restricting the guests from being eligible as recruitable knights in an administrative kingdom.

---

## Installation & Usage

1. **Download the Release**  
   - Go to the [releases](https://github.com/Tygrtraxx/Administrative_Government_Knight_Eligibility_Fix/releases) page.  
   - Download the version compatible with your current Crusader Kings III patch.
     
     
2. **Unzip the File**  
   After unzipping, you will see several items, such as:
    - `administrative_government_knight_eligibility_fix/`
    - `administrative_government_knight_eligibility_fix.mod`
    - `README.MD`
    

3. **Move the Required Files:**

  You only need:
  - The folder `administrative_government_knight_eligibility_fix/`
  - The file `administrative_government_knight_eligibility_fix.mod`

*Move both of these to:* `Documents/Paradox Interactive/Crusader Kings III/mod/`


4. **Verify File Paths**  
Confirm that your paths look like this:
    - `Documents/Paradox Interactive/Crusader Kings III/mod/administrative_government_knight_eligibility_fix/`
    - `Documents/Paradox Interactive/Crusader Kings III/mod/administrative_government_knight_eligibility_fix.mod`
      
    
5. **Enable the Mod**  
    - Open the Crusader Kings III launcher.  
    - Enable **Administrative Government - Knight Eligibility Fix** in the Mod Manager.  
    - Launch the game.
